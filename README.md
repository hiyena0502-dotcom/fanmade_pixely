# PIXELY : LOST SKY

잠뜰TV의 여러 상황극 세계에서 모든 **잠뜰**이 사라졌다는 설정으로 시작하는 비공식 팬메이드 미스터리 어드벤처입니다.

플레이어는 꿈뜰이가 되어 인물들과 대화하고, 남겨진 물건을 조사하고, 단서를 모으며 여러 세계를 따라갑니다. 잘못된 선택지는 게임오버 대신 다른 대화나 가벼운 사건으로 이어지도록 설계합니다.

## 현재 구조

- **HOME** — 현재 사건과 진행 상황
- **STORY** — 인물 대화, 물건 조사, 선택지, 단서 수집
- **CLICK** — 별가루를 모으는 짧은 보조 활동
- **CAPSULE** — 별가루로 기억 기록 수집
- **ARCHIVE** — 기억, 사건 단서, 세계 기록 보관

## 파일

- `index.html` — 전체 게임 화면
- `style.css` — 새 게임 UI 디자인
- `app.js` — 상태 저장, 스토리, 클릭, 캡슐, 아카이브
- `favicon.svg` — 사이트 아이콘

게임 진행 데이터는 브라우저 `localStorage`의 `pixely-lost-sky-v1` 키에 저장됩니다.
