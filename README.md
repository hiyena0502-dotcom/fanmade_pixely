# PIXELY SKY DIARY

푸른 하늘을 지나 펼쳐지는 픽셀리 팬메이드 다이어리입니다.

## 주요 화면

- 푸른 하늘 인트로와 다이어리 오픈 애니메이션
- 내용이 늘어나면 자동으로 펼침면을 만드는 페이지형 다이어리
- 시리즈별 기본 소개·등장인물·에피소드·명장면·관계성 기록장
- 카드가 실제로 뽑히는 픽셀 가챠
- 상세 메모와 관련 시리즈를 담을 수 있는 카드 컬렉션
- 설정창에서 카드·시리즈·시리즈 내부 기록 추가·수정·삭제
- 컬렉션·기본 목록·전체 초기화와 JSON 백업·불러오기
- 이전·다음 종이 버튼과 페이지 접힘 전환 애니메이션
- 1366×768부터 1920×1080까지를 우선한 PC 레이아웃

다이어리 데이터는 현재 브라우저의 `localStorage`에 저장됩니다. 다른 기기로 옮기거나 브라우저 데이터를 지우기 전에는 설정에서 JSON 백업을 만들어주세요.

별도의 설치 과정 없이 `index.html`을 열면 실행됩니다.
